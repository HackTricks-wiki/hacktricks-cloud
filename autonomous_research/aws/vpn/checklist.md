# VPN (Client VPN / Site-to-Site) — open ideas

The former empty stub now documents the valuable Standard-storage Site-to-Site VPN PSK download path.

- [ ] **Client VPN** — `ec2:ExportClientVpnClientConfiguration` / `ExportClientVpnClientCertificateRevocationList`:
  pull the client config (endpoint, DNS, split-tunnel, auth mode) for recon.
- [x] **Authorization-rule abuse** — exact-endpoint `ec2:AuthorizeClientVpnIngress` alone added an all-authenticated-users rule for a chosen CIDR. The caller could not list or revoke it. Published with the client-auth, association, route, security-group/NACL and application-auth boundaries; live fixture fully cleaned 2026-10-01.
- [x] **Route/target-network tamper** — exact endpoint + exact subnet `AssociateClientVpnTargetNetwork` selected the first VPC, made the endpoint available and installed the active VPC-local route; the same boundary allowed an additional `CreateClientVpnRoute` destination. Published with authentication, authorization-rule, routing, SG/NACL, application and same-VPC boundaries. The association, route, endpoint, managed ENI, ACM certificate, IAM principal and local keys were fully removed (2026-10-01).
- [x] **Client-certificate revocation boundary** — tested replacement validation and live authentication with positive/negative controls on a disposable associated endpoint. Unexpected security impact was confirmed; exploit details are withheld from the public repository and recorded only in the restricted local AWS report. All endpoint, association, certificate, IAM, local-key, ENI and session state was removed (2026-10-01).
- [x] **Site-to-Site peer takeover** — exact-VPN `ModifyVpnConnection` repointed an existing connection to a second controlled customer gateway while preserving tunnel settings; exact-VPN `ModifyVpnTunnelOptions` then installed an attacker-selected PSK. Published with the customer-gateway public-IP/appliance, routing and downstream-control prerequisites, explicit service-level persistence scope, endpoint-replacement downtime and default CloudTrail writes. The isolated VGW was never attached and all resources were deleted (2026-10-01).
- [x] **Site-to-Site configuration download** — `GetVpnConnectionDeviceSampleConfiguration` discloses live Standard-storage PSKs; Secrets Manager storage redacts them and remains a separate `GetSecretValue` boundary. Public page added with bounded network-position prerequisites.
