# CodeGuru Security end-of-support audit — 2026-09-27

## Decision

Do not add a public attack page. Amazon CodeGuru Security support ended on 2025-11-20, and its scan inventory now returns `FeatureNoLongerAvailableException`. The residual account-configuration and zero-metrics reads have no meaningful offensive value. Record this exclusion so the stale SDK/CLI model does not repeatedly generate false research leads.

## Modeled surface

AWS CLI `2.34.45` still ships 13 operations:

```text
BatchGetFindings
CreateScan
CreateUploadUrl
GetAccountConfiguration
GetFindings
GetMetricsSummary
GetScan
ListFindingsMetrics
ListScans
ListTagsForResource
TagResource
UntagResource
UpdateAccountConfiguration
```

The current Service Authorization Reference likewise still lists these actions plus the permission-only `DeleteScansByCategory` and `ListFindings`. Scan resources use `arn:aws:codeguru-security:<region>:<account>:scans/<scan-name>` and support global resource/request tag conditions. Historically, `CreateUploadUrl` returned a presigned S3 upload URL, required headers and a code-artifact ID; `CreateScan` consumed that artifact and findings could contain sensitive source context. Those shapes are not a current usable technique after service retirement.

## Security disposition

- No current post-exploitation value: no accessible scan inventory or findings were demonstrated.
- No current presigned-upload/bearer technique: no URL was created after retirement.
- No PassRole, role execution, resource-policy, cross-account or unauthenticated surface exists in the modeled API.
- The residual KMS configuration reference is metadata, not key material, and defaults empty.
- No unexpected AWS defect was found; no private report was created.

## Cleanup proof

Every live call was read-only. No IAM role/policy, KMS key/grant, S3 object, upload artifact, scan, finding or CodeGuru configuration was created or changed. There is no test residue and no cleanup waiter.
