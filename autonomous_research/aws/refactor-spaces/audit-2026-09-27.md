| A shared participant can create an attacker URL service and a path/method route to intercept application requests | **Confirmed expected behavior** by current API semantics, sharing docs, live RAM permission, and `CreateService` / `CreateRoute` IAM probes that passed authorization to resource lookup | Added post-exploitation technique |

### `ListServices` documentation mismatch

The current Service Authorization Reference says `ListServices` requires the environment resource. A disposable role granted only:

```text
arn:aws:refactor-spaces:us-east-1:228478051196:environment/env-0000000000
```

The service denied the request and named the evaluated resource:

```text
arn:aws:refactor-spaces:us-east-1:228478051196:environment/env-0000000000/application/app-0000000000/service/*
```

A second role granted that exact service-child wildcard. The same call then passed IAM and returned `ResourceNotFoundException` for the fake environment. This is operationally important for least-privilege policy construction but does not create a security boundary bypass, so it was not treated as a vulnerability.

## RAM permission result

The default managed permission was version 2, `ATTACHABLE`, and allowed:

- read/list access to the environment, applications, services, routes, tags, and environment VPCs;
- `CreateApplication`, `CreateService`, and `CreateRoute` without a creator restriction;
- `DeleteApplication`, `DeleteService`, `DeleteRoute`, `UpdateRoute`, `TagResource`, and `UntagResource` only when `refactor-spaces:CreatedByAccountIds` equals `${aws:PrincipalAccount}`.

Version 1 was non-default and `UNATTACHABLE`; version 2 added `UpdateRoute` to the creator-conditioned mutations.

No RAM share was created because there was no real environment to associate and an external invitation was unnecessary.

## Logging and unauthenticated behavior

AWS documents every Refactor Spaces API call as a CloudTrail management event with `eventSource=refactor-spaces.amazonaws.com`. Event History returned the signed `ListEnvironments` probe with `readOnly=true`. The exact-resource failure probes had not yet appeared during the short indexing window; this is normal Event History delay, not evidence of missing logging.

RAM share changes use `ram.amazonaws.com`. Application data-plane requests do not produce one Refactor Spaces management event per request and require API Gateway/WAF/backend/network telemetry.

Unsigned `ListEnvironments` returned `MissingAuthenticationTokenException`. No unsigned ID oracle or data response was found. A Regional application endpoint is public-internet reachable by design, but no application existed to establish whether a specific proxied workload accepted anonymous requests.
