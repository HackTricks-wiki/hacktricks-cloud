# DynamoDB post-exploitation stealth audit, 2026-09-26

Twenty DynamoDB post-exploitation sections had impact statements and expandable log tables but lacked explicit stealth ratings. Added ratings that distinguish optional item/stream data events from default management events for table configuration, backup, restore, and destination writes. AWS [lists DynamoDB data-plane events](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/logging-using-cloudtrail.html); [CloudTrail does not log data events by default](https://docs.aws.amazon.com/awscloudtrail/latest/userguide/logging-data-events-with-cloudtrail.html). Broad scans and writes can still show up in capacity metrics or application state. This was documentation-only; no DynamoDB data or table was touched.
