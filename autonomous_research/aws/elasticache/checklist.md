# ElastiCache — open ideas

- [x] **Enum page** — refreshed node/serverless/global inventory, snapshot support, public Valkey 9 endpoints and IAM-only public authentication on 2026-10-01; see `documentation-corrections-2026-10-01.md`.
- [x] **Privesc / lateral via RBAC** — live exact-user test confirmed that `elasticache:ModifyUser` alone can simultaneously replace a restricted user's password and ACL with `on ~* +@all`, without Describe, group/cache, secret/KMS, PassRole, or SLR-management permission. Published on the privesc page; see `modify-user-rbac-escalation-2026-10-01.md`.
- [x] **Post-exploitation / legacy AUTH takeover** — exact-group `ModifyReplicationGroup --auth-token ... --auth-token-update-strategy ROTATE` added a second attacker-known token while preserving the old token; both completed TLS `AUTH` + `PING`. Published; see `modify-replication-group-auth-rotation-2026-10-01.md`.
- [ ] **Other replication-group mutations** — test user-group removal (documented to disable access control), security-group replacement, log-delivery disablement and snapshot-retention changes. Keep `TestFailover` / pure disruption out unless it reveals a stronger boundary.
- [x] **Snapshot export correctness** — removed unsupported `CopySnapshot`-alone/SLR/cross-account claims, added current caller-side S3 permissions and same-account/Region boundaries, and made serverless S3 dependencies conservative pending a live test. See `documentation-corrections-2026-10-01.md`.
- [ ] **Serverless caches** — check `CreateServerlessCacheSnapshot` / `ExportServerlessCacheSnapshot` for an exfil path analogous to the RDS snapshot-share technique.
- [x] **Authentication invariants** — exact-user attempts confirmed that Redis no-password users cannot transition to Valkey and mismatched ID/name users cannot transition to IAM auth. Both fail closed and remain unchanged; see `authentication-invariants-2026-10-01.md`.
- [x] **`ModifyUserGroup` secondary authorization** — exact group alone failed on the added-user ARN; exact group plus add/remove user ARNs succeeded; an ungranted outsider failed on its user ARN. Updated persistence minimum; see `modify-user-group-authorization-2026-10-01.md`.
- [ ] **Remaining free boundaries** — exact-resource `DescribeUsers`/`DescribeUserGroups` isolation; `CreateUserGroup` prospective-user resource checks; concurrent modify/delete propagation; failed-call AUTH-token redaction (successful token rotation is already confirmed redacted).
