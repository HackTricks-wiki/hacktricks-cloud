# AWS Application Cost Profiler retirement audit — 2026-09-27

## Outcome

AWS Application Cost Profiler is not a current attack surface. AWS's product page states that the service was discontinued on **2024-09-30** and stopped accepting new customers before that date. A signed `ListReportDefinitions` request to the modeled `us-east-1` endpoint on 2026-09-27 failed before HTTP with `Could not connect to the endpoint URL`; the endpoint no longer resolved/replied.

No HackTricks service or attack page was added. Publishing the stale SDK operations as current techniques would be misleading.

## Residual model reviewed

The AWS CLI 2.34 service model still contains six SigV4 operations:

- `ListReportDefinitions` and `GetReportDefinition`;
- `PutReportDefinition`, `UpdateReportDefinition`, and `DeleteReportDefinition`;
- `ImportApplicationUsage`.

The old model permits at most one report definition. Its reads expose the report ID, description, frequency, CSV/Parquet format, S3 destination bucket/prefix, and timestamps. The import operation accepted an S3 bucket/key and copied that object into an AWS-owned bucket for asynchronous processing.

## Historical ideas rejected for the current book

| Candidate | Historical effect | 2026 decision |
| --- | --- | --- |
| Report-definition reconnaissance | Discover the destination and cadence of tenant-level cost reports. | Retired service; no current resource to enumerate. |
| `UpdateReportDefinition` destination redirection | Redirect future tenant cost-allocation reports to another S3 destination, subject to the old delivery prerequisites. | Retired service; cannot establish or verify a live report. |
| `ImportApplicationUsage` poisoning | Submit attacker-controlled tenant-usage rows from a readable S3 object and corrupt later allocation reports. | Retired service; the asynchronous ingestion path is unavailable. |
| Delete the report definition | Stop future allocation reports. | Availability-only even historically, and now obsolete. |
| PassRole/resource-policy/cross-account pivot | None of the six modeled inputs contains a role ARN or resource policy. | Rejected by API model; no distinct primitive. |
| Unauthenticated enumeration | The service model requires SigV4. | No endpoint remains on which to perform a meaningful unsigned boundary test. |

The report redirection and import poisoning ideas would have been plausible integrity/ confidentiality techniques while the service operated, but they should not be presented as usable AWS attacks after retirement. Revisit only if AWS launches a replacement or restores a supported endpoint.

## Telemetry and cleanup

- The former CloudTrail event source was `application-cost-profiler.amazonaws.com`; no service-side event can be expected for the 2026 request because the connection failed before reaching AWS.
- No report definition, S3 object, S3 bucket, IAM principal, policy, EventBridge rule, or other resource was created, updated, or deleted.
- There is no test residue to clean up.
- No unexpected security behavior was found and no private disclosure file was created.
