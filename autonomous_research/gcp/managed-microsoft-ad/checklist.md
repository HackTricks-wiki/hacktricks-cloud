# Managed Microsoft AD - open research checklist

- [ ] With explicit approval and a disposable domain, capture the response fields and Cloud Audit Logs record for delegated-administrator password reset without exposing the returned password.
- [ ] With explicit approval, verify which exported Windows event IDs are generated by use of the reset credential for logon, group membership, DNS, and GPO changes.
- [ ] Reassess trust attachment only if a concrete path is found that grants a trusted attacker identity useful authorization without separately obtaining delegated-administrator credentials.
- [ ] Monitor delegated-administrator group/right changes for newly exposed access to Google-reserved forest operations.
